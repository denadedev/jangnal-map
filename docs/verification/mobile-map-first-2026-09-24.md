# 모바일 지도 우선 화면 로컬 확인

**대상:** 모바일 홈 지도 우선 UI  
**상태:** 자동 검증 통과. 실제 NAVER 지도·기기 확인은 미완료  
**수동 확인:** 사용자가 로컬 화면을 확인함. 현재 작업 환경에는 `NEXT_PUBLIC_NAVER_MAPS_CLIENT_ID`가 없어 fallback 화면만 확인 가능했음.

## 실행

저장소에 이미 설정된 `NEXT_PUBLIC_NAVER_MAPS_CLIENT_ID`를 사용해 웹 앱을 실행한다. 키 값은 문서나 채팅에 복사하지 않는다.

```bash
pnpm --filter @jangnal-map/web dev
```

Chromium 개발자 도구에서 320×568, 375×667, 375×844, 430×844 뷰포트를 확인한다. iPhone Safari와 Android Chrome에서도 키보드와 안전 영역을 확인한다.

## 확인 목록

- [ ] 홈 첫 화면에서 검색·메뉴·날짜 필터가 지도 위에 놓이고 지도가 화면의 중심 영역을 차지한다.
- [ ] 접힌 결과 바는 한 번 탭하면 절반 높이 목록으로 열린다. 목록은 전체 높이로도 확장되고 `지도 보기`로 접힌다.
- [ ] 검색어와 날짜 필터가 동작하고 URL의 `q`, `when`, `date` 값이 유지된다.
- [ ] 지도에서 화면 가장자리 쪽 핀을 선택하면 시장 미리보기가 열리고 선택 핀이 검색 영역과 시트 사이에 보인다.
- [ ] 미리보기의 다음 장날·운영 상태, 한 줄 주소, `상세 보기`, `닫기`가 읽히고 눌린다.
- [ ] 미리보기 닫기와 브라우저 뒤로가기는 이전 결과 높이로 돌아간다. 상세 보기 후에도 URL에 중복 히스토리 항목을 추가하지 않는다.
- [ ] 시장을 고른 뒤 바로 닫으면 선택 전 지도 중심·줌이 돌아오고, 미리보기 중 지도를 직접 끌거나 확대하면 닫은 뒤 사용자가 움직인 지점을 유지한다.
- [ ] 목록에서 고른 시장은 전체 상세로 열리고, 뒤로가기·닫기 후 검색, 날짜, 스크롤 위치와 포커스를 복원한다.
- [ ] 전체 상세에서는 배경 지도·검색에 포커스가 가지 않고 Escape로 닫힌다.
- [ ] 검색창에 초점을 두고 키보드를 열면 목록이 키보드 위에서 스크롤된다. 키보드를 닫으면 기존 시트 높이로 돌아온다.
- [ ] 시트가 접히거나 미리보기일 때 현재 위치 버튼, 선택 핀, NAVER 로고와 저작권 표시가 겹치지 않는다.
- [ ] 시장별 방문 정보는 결과 목록 안에서 열리고, 메뉴에서 서비스 소개·개인정보·약관·데이터 기준·제보 링크를 연다.
- [ ] 위치 권한 거부, 좌표 없는 시장, 결과 없음, 지도 키/SDK 실패에서도 검색과 전체 목록을 사용할 수 있다.
- [ ] 가로 오버플로우, 텍스트 잘림, 홈 인디케이터 영역의 버튼 겹침이 없다.

## 자동 검증 결과

- `pnpm test` — 통과: 웹 195, 데이터 감사 35, 스크립트 14 tests.
- `pnpm typecheck` — 통과.
- `pnpm build` — 통과.
- `pnpm --filter @jangnal-map/web exec playwright test e2e/mobile-map-space.spec.ts --project=mobile-320 --grep "short viewports|visit guides"` — 통과: 2 tests.
- 전체 Playwright suite는 올바른 production standalone 서버 설정 전 실행되어 유효한 결과로 보지 않았음. 수정 후 핵심 레이아웃 테스트만 재실행함.

실제 NAVER Maps SDK에서 핀·클러스터 선택, 위치 권한, 지도 로고와 저작권 표시, iPhone Safari·Android Chrome 동작은 별도로 확인해야 한다.

## 대표 과업

Playwright의 모바일 Chromium에서 `평택 검색 → 시장 선택 → 다음 장날 확인` 흐름이 모든 프로젝트에서 통과했다. 테스트 케이스 실행 시간은 약 1.5–1.7초였지만, 이는 브라우저 자동화 실행 시간이며 실제 사용자 스톱워치 측정값은 아니다. 실기기 수동 측정은 아래 미실행 목록에 남긴다.

## 실기기 체크리스트

이 작업 환경에는 연결된 iPhone 또는 Android 기기가 없어 다음 항목은 미실행이다.

- iPhone Safari: 시트 드래그, 브라우저 뒤로가기, 네이티브 날짜 선택기, 가상 키보드, safe-area, iOS 설치 안내
- Android Chrome: 시트 드래그, 브라우저 뒤로가기, 가상 키보드, safe-area, 위치 허용·거부, `beforeinstallprompt` 설치 흐름
- 두 기기 공통: 외부 길찾기 전환과 대표 과업 실제 소요 시간

따라서 물리 기기별 10초 목표와 iOS/Android 설치·권한 동작은 배포 전 실제 기기에서 한 번 더 확인해야 한다. 자동화된 모바일 레이아웃·상태·오버플로우 검증은 완료됐다.

## 알려진 제한

- Playwright 서버는 현재 `next start`로 실행하며 Next.js standalone 설정 경고가 출력된다. 정적 자산과 테스트 결과는 정상이다.
- 지도 SDK 키 없이 실행하는 결정적 fallback 경로를 자동 검증했다. 실제 Naver Maps SDK 핀·클러스터 상호작용은 유효한 키와 실환경에서 별도 확인해야 한다.

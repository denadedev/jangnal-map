# PRD: 지역별 장날 랜딩 페이지

- 문서 상태: DRAFT (사용자 검토 전)
- 작성일: 2026-10-14
- 기준 문서: `docs/product/PRD.md` 1.1, 기능 브레인스토밍 2순위
- 근거 데이터: `apps/web/public/data/markets.json`, `market-editorial.json`, `src/app/sitemap.ts`, `src/lib/market-seo.ts` (2026-10-14 기준)

## 1. 요약

"경북 장날", "오늘 장날 어디", "4·9일장" 같은 검색어를 받는 고정 URL 페이지를 만든다. 각 페이지는 해당 지역(또는 장날 끝자리)의 **오늘·이번 주말 열리는 장**, **한 달 장날 달력**, **전체 장 목록**, **사람이 쓴 지역 소개**를 담는다. 지금은 검색 유입을 홈과 검수된 시장 상세 40여 곳만 받는다.

## 2. 현재 상태와 제약 (확인한 사실)

| 항목 | 수치·내용 |
|---|---|
| 운영 중 정기 장날 시장 | 409곳 |
| 그중 검수 완료(독립 URL·sitemap 대상) | 40곳 (`isMarketIndexable`) |
| 시·도별 정기 장날 시장 | 경북 79, 경남 69, 전남 63, 경기 36, 충남 35, 전북 34, 충북 31, 강원 23, 울산 11, 제주 9, 대구 8, 세종 4, 광주·부산 2, 인천·서울·대전 1 |
| 시·군·구 | 145곳에 분포, 3곳 이상인 곳 68개 (경주 11, 울주 8, 창원 8 …) |
| 끝자리 패턴 | 4·9일 87, 2·7일 87, 5·10일 85, 3·8일 84, 1·6일 66 |
| 현재 정책 | 미검수 시장은 독립 URL을 만들지 않고 지도 선택 상태(`/?when=all&market=…`)로만 연결 |
| 데이터 이슈 | 일부 주소의 시·도가 `전북특별차치도`(오타)로 들어 있음. `region-aliases.ts`가 이미 흡수 중 |

**설계에 주는 의미:** 미검수 시장이 대부분이라 지역 페이지가 시장 상세 링크 모음이 되면 얇은 콘텐츠가 된다. 지역 페이지 자체가 고유한 정보(날짜별 묶음, 달력, 지역 소개)를 가져야 한다.

## 5. 솔루션

### 5.1 URL 구조
고정 URL만 만든다. 날짜가 들어간 URL(`/2026-10-18`)은 무한히 늘어나고 내용이 겹치므로 만들지 않는다.

| 경로 | 개수 | 예 |
|---|---|---|
| `/jangnal` | 1 | 전국 허브: 오늘 열리는 장 요약 + 지역·패턴 링크 |
| `/jangnal/{시·도}` | 1단계 8개 | `/jangnal/gyeongbuk` (경북) |
| `/jangnal/days/{패턴}` | 5 | `/jangnal/days/4-9` |
| `/jangnal/{시·도}/{시·군}` | 2단계 최대 68개 | `/jangnal/gyeongbuk/gyeongju` |

- 시·도 슬러그는 `region-aliases.ts`의 영문 이름을 쓴다 (기본값으로 정함. 시장 상세처럼 한글 슬러그를 원하면 바꿀 수 있음).
- 1단계 시·도는 정기 장날 시장 20곳 이상인 8곳(경북·경남·전남·경기·충남·전북·충북·강원)으로, 409곳 중 370곳을 덮는다. 나머지 시·도는 허브에서 지도로 연결한다.

### 5.2 페이지 구성 (시·도 페이지 기준)
1. **제목·요약:** "경북 장날 · 5일장 79곳의 오늘·이번 주말 장날". 기준 날짜(한국 날짜)와 자료 기준일 표시.
2. **오늘 열리는 장:** 오늘 날짜 끝자리에 해당하는 장 목록과 시·군. 없으면 다음 장날 안내.
3. **이번 주말 열리는 장:** 토·일 각각.
4. **한 달 장날 달력:** 날짜 칸마다 열리는 장 수, 누르면 그 날짜 목록. 끝자리 규칙상 매일 서로 다른 장이 열린다는 점이 지역 페이지만의 정보가 된다.
5. **시·군별 전체 목록:** 시장명, 장날 패턴, 상설 겸업 여부, 주차 여부. 검수 시장은 상세 URL, 미검수 시장은 기존 정책대로 지도 선택 상태로 연결 (`getMarketBrowsePath`).
6. **지역 소개(사람이 작성):** 지역 장날의 특징, 대표 장 2~3곳, 방문 팁. 출처와 작성일 표기. `market-editorial.json`과 같은 방식의 `region-editorial.json`으로 관리하고 검증 테스트를 둔다.
7. **자주 묻는 질문:** "경북에서 오늘 열리는 장은?", "장날이 31일이면?"(31일 다음 1일 휴장 규칙 설명) 등. 본문 내용과 일치하는 것만.
8. **연결:** 지도에서 이 지역 보기, 인접 시·도 페이지, 패턴 페이지.

패턴 페이지는 4~7을 "같은 끝자리 장 전국 목록(시·도별)"로 바꾼 구성이다.

### 5.3 날짜 갱신
- 내용 중 "오늘·이번 주말"은 날마다 바뀐다. 한국 날짜 기준으로 계산하고(`korea-date.ts`), 페이지는 서버에서 렌더링한 뒤 하루 단위로 재생성(ISR)한다. 재생성 실패 시 오래된 "오늘"이 보이지 않도록 클라이언트에서 기준 날짜를 다시 확인해 다르면 해당 영역만 다시 계산한다.
- 달력·전체 목록은 날짜와 무관한 안정 콘텐츠라 검색 엔진에 일관된 본문을 준다.

### 5.4 SEO 처리
- `sitemap.ts`에 1단계 페이지 추가 (`changeFrequency: "daily"`).
- 페이지별 고유 title·description, canonical, `ItemList` 구조화 데이터 (시장 상세 URL이 있는 항목만 URL 포함).
- 시장 상세 하단 "같은 지역 장날"(`findRelatedMarkets`)에 시·도 페이지 링크 추가. 홈 메뉴에 "지역별 장날" 링크 추가.
- 네이버 서치어드바이저에 sitemap 제출 (검색 인증 태그는 이미 있음).

### 5.5 제외 범위
- 날짜별 URL, 시·군 페이지 일괄 자동 생성(지역 소개 없는 페이지 금지)
- 영어 지역 페이지 (`/en`은 sitemap 정책상 안내 페이지만 색인 중. 후속 검토)
- Threads 게시물에 지역 링크 붙이기: n8n 워크플로 수정이므로 출시 후 별도 요청으로 진행

## 6. 기능 요구사항

- **R1.** `/jangnal`, 1단계 시·도 8개, 패턴 5개 페이지를 생성한다.
- **R2.** 장날 계산은 `getMarketDates`·`getNextMarketDate`를 재사용해 지도·상세와 같은 결과를 보장한다.
- **R3.** 시·도 판별은 주소 첫 단어 + `region-aliases.ts` prefix로 하고, `전북특별차치도` 오타를 포함한 모든 시장이 정확히 한 시·도에 속하는지 테스트한다.
- **R4.** 지역 소개가 없는 시·도 페이지는 빌드에서 제외한다 (테스트로 강제).
- **R5.** 미검수 시장에 새 독립 URL을 만들지 않는다.
- **R6.** Umami 이벤트: `region-market-click`(검수/미검수 구분), `region-map-open`.
- **R7.** 지도 SDK 없이도 페이지 전체가 동작한다 (서버 렌더 HTML).

## 8. 검증할 가정

| # | 가정 | 확인 방법 | 실패 시 |
|---|---|---|---|
| 1 | 지역·패턴 장날 검색 수요가 있다 | 출시 전 Search Console 검색어, 네이버 데이터랩 | 패턴 페이지만 먼저 출시 |
| 2 | 매일 바뀌는 "오늘" 영역이 있어도 색인이 안정적이다 | 출시 후 2주 색인·스니펫 확인 | 오늘 영역을 클라이언트 렌더로 전환 |
| 3 | 지역 페이지가 얇은/도어웨이 페이지로 판정되지 않는다 | AdSense·Search Console 경고 확인 | 페이지 수 축소, 소개 보강 |
| 4 | 미검수 시장 링크(지도 연결)도 사용자가 충분히 쓴다 | R6 이벤트 | 검수 우선순위를 클릭 많은 시장으로 조정 |

## 9. 릴리스

- **1단계:** 허브 + 패턴 5개 + 시·도 8개 (지역 소개 8편 필요).
- **2단계:** 시장 3곳 이상 시·군 중 클릭 상위부터 지역 소개를 붙여 순차 추가.
- **3단계:** Threads 자동 게시에 "오늘 열리는 장" 지역 페이지 링크 연결 (n8n, 별도 확인 후).
- 출시 전: `pnpm test`, `pnpm typecheck`, `pnpm build`, Playwright, 페이지별 메타·sitemap 확인.

## 10. 열린 결정
1. URL 슬러그: 영문(`/jangnal/gyeongbuk`, 기본값) 또는 한글(`/jangnal/경북`)
2. 지역 소개 작성 주체: 직접 작성 또는 초안 생성 후 검수
3. AdSense 심사 중 출시 여부: 심사 결과 후 출시(안전) 또는 바로 출시

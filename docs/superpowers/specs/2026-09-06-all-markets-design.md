# 전체 전통시장 표시 설계

## 목적

현재 정적 MVP는 정기 장날과 좌표가 모두 확인된 시장 400곳만 공개한다. 이를 원본 공공데이터 1,393곳 전체로 확장해 제천중앙시장 같은 매일 운영 상설시장도 검색, 목록, 지도와 날짜 필터에서 찾을 수 있게 한다.

## 데이터 모델

공개 데이터에는 원본 1,393행을 모두 포함한다. 일정은 다음 세 유형의 구분된 유니언으로 저장한다.

- `daily`: 원본 개설 주기가 `매일`인 시장
- `digit-pair`: `1일+6일`처럼 두 장날을 계산할 수 있는 시장
- `unknown`: 비어 있거나 현재 규칙으로 안전하게 계산할 수 없는 일정

위도와 경도는 nullable로 변경한다. 좌표가 없는 시장도 검색과 목록에는 포함하지만 지도 핀은 만들지 않는다. 일정이 불명확한 시장도 `전체`에는 포함하되 날짜 기반 결과에서는 제외한다.

기존과 동일하게 원본에는 운영 상태가 없으므로 최초 값은 `운영`, `statusVerified: false`로 유지한다. ID는 시장명, 주소, 좌표와 원본 일정을 조합한 결정적 해시로 생성한다.

## 필터 의미

- `전체`: 일정과 무관하게 1,393곳 전체를 표시한다.
- `오늘`: 매일 운영 시장과 오늘이 장날인 정기시장만 표시한다.
- `이번 주`: 매일 운영 시장과 오늘부터 7일 이내에 한 번 이상 열리는 정기시장을 표시한다. 일요일에 `오늘`과 결과가 같아지는 문제를 피하기 위해 달력 주의 남은 기간이 아니라 rolling 7일을 사용한다.
- `주말`: 매일 운영 시장과 다음 완전한 토요일·일요일 중 한 번 이상 열리는 정기시장을 표시한다. 오늘이 토요일이면 오늘과 다음 날을 사용하고, 오늘이 일요일이면 다음 주 토요일·일요일을 사용한다.
- `날짜 선택`: 선택한 하루에 운영하는 시장을 표시한다. 버튼을 누르면 지원 브라우저에서 네이티브 날짜 선택기를 즉시 열고, 미지원 브라우저에서는 입력에 포커스한다.

기본 필터는 기존대로 `이번 주`를 유지한다. URL에는 `when=all|today|week|weekend|date`를 저장하고 직접 날짜는 `date=YYYY-MM-DD`로 저장한다.

검색어는 모든 필터 결과에 추가로 적용한다. 필터 변경으로 선택한 시장이 결과에서 제외되면 상세 선택을 해제한다.

## 표시 규칙

일정 유형별 문구는 다음과 같다.

| 유형 | 핀·목록 | 상세 화면 |
|---|---|---|
| 매일 | `매일` | `매일 운영` |
| 정기 장날 | 다음 날짜 `M/D` | 다음 장날과 해당 월 장날 |
| 일정 미확인 | `일정 확인` | `운영 일정 확인 필요` |

좌표가 없는 시장은 목록에 `위치 확인 필요`를 표시하고 길찾기 링크를 제공하지 않는다. 주소, 전화와 주차 정보 등 확인 가능한 상세정보는 그대로 제공한다.

## 지도와 군집

전체 화면에서 1,000개 이상의 이름표를 한꺼번에 렌더링하지 않는다.

- 낮은 확대 단계에서는 화면상의 가까운 시장을 격자 단위로 묶어 숫자 군집으로 표시한다.
- 군집을 선택하면 해당 중심으로 이동하고 확대한다.
- 충분히 확대하면 현재 지도 영역 안의 개별 시장만 `시장명 · 매일`, `시장명 · 다음 장날` 또는 `시장명 · 일정 확인` 핀으로 표시한다.
- 필터나 검색어가 변경되면 현재 결과를 기준으로 군집과 개별 핀을 다시 계산한다.
- 좌표가 없는 시장은 지도 집계에서 제외하고 목록 상단 안내에 개수를 표시한다.

지도 군집 계산은 브라우저에서 수행하며 외부 위치 데이터나 별도 백엔드를 추가하지 않는다.

## 모바일 웹

- 날짜 필터는 700px 이하에서 두 줄 안에 배치하고 가로 페이지 스크롤을 만들지 않는다.
- `전체`, `오늘`, `이번 주`, `주말`, `날짜 선택`을 모두 키보드와 터치로 조작할 수 있게 한다.
- 낮은 확대 단계의 군집으로 핀 중첩과 DOM 개수를 줄인다.
- 개별 시장을 선택하면 기존 하단 상세 시트를 사용한다.
- 현재 위치 버튼은 지도 우측 상단에 유지하며 필터 및 군집과 겹치지 않게 한다.
- 긴 전체 목록은 지도와 별개로 스크롤할 수 있어야 한다.

## 오류와 불완전 데이터

- 지도 SDK 실패 시 전체 시장 목록과 필터는 계속 사용할 수 있다.
- 일정 미확인 시장은 전체 검색에서 숨기지 않고 명시적으로 표시한다.
- 좌표가 없는 시장을 선택해도 상세 화면이 열리며 위치 확인 필요 상태를 표시한다.
- 공개 JSON 로딩 실패 시 기존 재시도 화면을 유지한다.

## 성능 기준

- 전국 초기 지도에서는 개별 시장 핀 1,393개를 동시에 DOM에 만들지 않는다.
- 필터 변경 후 군집과 목록은 사용자의 입력을 막지 않아야 한다.
- 정적 JSON은 한 번만 내려받아 TanStack Query 캐시에 유지한다.
- 지도에는 현재 확대 단계와 화면 영역에 필요한 군집 또는 개별 핀만 유지한다.

## 검증 기준

- 공개 JSON에 원본과 동일한 1,393개 시장이 존재한다.
- `제천중앙시장` 검색 시 상설시장 정보와 `매일` 문구가 표시된다.
- 오늘·이번 주·주말·직접 날짜 필터에 매일 운영 시장이 포함된다.
- 일정 미확인 시장은 전체에만 포함된다.
- 좌표 없는 시장은 목록과 상세에는 나타나고 지도와 길찾기에서는 제외된다.
- 전국 확대 단계에서 군집이 표시되고 확대 후 개별 시장명 핀으로 전환된다.
- 데스크톱과 375px 모바일에서 필터, 지도, 목록과 상세 시트가 가로 스크롤 없이 작동한다.
- 기존 지도 실패 대체 화면, 검색, URL 복원과 현재 위치 기능에 회귀가 없다.

## 제외 범위

- 데이터베이스 및 백엔드 API
- 자동 공공데이터 동기화
- 사용자 제보와 관리자 수정 화면
- 운영·폐장 상태의 외부 검증
- Vercel 배포

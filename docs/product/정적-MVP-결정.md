# 오늘장날 정적 MVP 결정

- 상태: APPROVED
- 승인일: 2026-09-03
- 적용 단계: 최초 공개 버전

## 결정

최초 공개 버전은 백엔드, 데이터베이스와 사용자 제보 저장 기능 없이 Next.js 정적 데이터 기반으로 제공한다.

```text
공공데이터 CSV
  → 조사·정규화
  → 공개 가능한 400개 markets.json
  → Next.js
  → Vercel Hobby
```

## 포함

- 전국 지도
- 시장명과 다음 장날이 함께 보이는 핀
- 오늘·이번 주·주말·직접 날짜 필터
- 시장명·지역 검색
- 시장 상세정보와 월간 장날
- 출처와 기준일
- 모바일 반응형 UI
- 지도 SDK 실패 또는 키 미설정 시 목록 대체 화면

## 보류

- NestJS API
- PostgreSQL/PostGIS와 TypeORM migration
- K3s, Harbor, Argo CD 백엔드 배포
- 사용자 제보 저장
- 관리 CLI와 관리자 웹페이지

DB migration 작업은 `data-audit` 브랜치에 보존한다. 제보 저장 또는 수동 수정 빈도가 증가할 때 백엔드 단계에서 재검토한다.

## 배포 승인 게이트

Vercel에는 자동 배포하지 않는다. 로컬 구현·테스트·브라우저 검증 결과를 사용자가 직접 확인하고 배포를 명시적으로 승인한 뒤 별도 단계에서 배포한다.

## 데이터 원칙

- 원본 1,393개 중 장날과 좌표가 모두 검증된 400개만 공개 JSON에 포함한다.
- `2일+5일`, `2일+4일+7일+9일`과 좌표가 없는 장날 후보는 공개하지 않는다.
- `5일+10일`은 날짜 끝자리 `5`, `0`으로 정규화한다.
- 다음 장날과 날짜 필터는 브라우저에서 계산한다.
- 정적 JSON 수정은 원본 조사 도구를 다시 실행하고 Vercel을 재배포하는 방식으로 관리한다.

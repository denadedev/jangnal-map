# 오늘장날 영어 첫 출시 기획

- 작성일: 2026-09-28
- 상태: 구현·자동 검증 완료. 실기기 지도 앱 연결, 영어 사용자 관찰, 공개 후 검색 유입 확인은 후속 검증 항목이다. 접근법 C(방문 가능한 영어 탐색)와 범위 유지가 사용자 선택으로 확정됨.
- 합의된 목표: 영어 검색으로 유입된 사용자가 기본 메뉴와 시장 탐색 화면도 영어로 읽을 수 있게 한다.
- 2026-09-28 초안의 ‘영어 안내 페이지 한 장’ 범위를 사용자의 후속 요청에 맞춰 확장한다.

## 사용자에게 보이는 결과

- `/en`: 영어 안내 페이지. 한국 전통시장과 5일장을 짧게 설명하고 영어 시장 지도로 연결한다.
- `/en/map`: 기존 전국 지도와 목록을 영어 UI로 사용한다. 검색·날짜 필터·시장 상세 시트·공유·오류·빈 결과도 영어로 표시한다.
- `/`: 기존 한국어 지도. 한국어 시장 페이지와 운영자용 기능은 유지한다.
- 영어 화면에는 `한국어` 링크, 한국어 화면에는 `English` 링크를 둔다. 각 링크는 대응하는 지도 화면으로 이동한다.

검색엔진 노출을 위한 `/en`은 서버에서 읽을 수 있는 실제 영어 본문과 영어 제목·설명을 제공한다. `/en/map`의 주 목적은 방문자가 탐색을 계속하는 것이며 영어 시장별 독립 페이지를 만들지는 않는다. 검색 노출과 순위는 보장하지 않는다.

## 첫 출시에서 번역할 내용

| 영역 | 영어 지원 |
| --- | --- |
| 안내 페이지 | 브랜드 소개, 상설시장과 장날의 차이·겹침, 장날에 방문할 이유, 5일장 예시, 지도 사용법, 방문 전 확인 사항, 데이터 출처 안내 |
| 공통 메뉴 | 브랜드 보조 문구, 언어 전환, 지도·서비스 소개·제보 등 보이는 링크 이름과 한국어 페이지 표시 |
| 지도·목록 | 검색창, 날짜 선택, 지도 상태, 결과 수, 선택·닫기, 목록 열기, 위치 사용, 초기화, 로딩·오류·빈 결과 문구 |
| 시장 상세 | 일정 유형·다음 장날·방문 정보의 라벨, 주차·정보 없음 상태, 출처·확인일, 길찾기·공유 버튼과 결과 메시지 |
| 온누리 요약 | 시장 상세에 보이는 카드의 기본 문구와 집계 날짜만 영어로 표시; 공식 사이트가 한국어임을 링크에 표기 |
| 날짜 | 사용자에게 보이는 월·일·요일과 장날 설명을 영어로 표시. 5일장 규칙을 단순한 ‘5일마다’로 잘못 설명하지 않는다 |

시장 이름·주소·공공데이터 출처의 고유명사는 한글 원문을 유지한다. 검수 없이 영문 이름이나 영문 주소를 자동 생성하지 않는다. 한국어 명칭에는 필요 시 `lang="ko"`를 지정한다.

영어 지도에서는 17개 시·도 영문명과 자주 쓰는 표기를 해당 한글 행정구역에 매핑해 검색한다. `Seoul`, `Busan`, `Jeju` 같은 지역 입력으로 결과를 찾을 수 있게 하며 한글 시장명·주소 검색도 유지한다. 시장별 영문명·로마자 검색은 제공하지 않는다. 검색창은 `Search a region in English or a market name in Korean`처럼 실제 범위를 설명한다. 원본 주소에는 `전북특별차치도` 표기가 있으므로 전북 매핑을 검증된 원본 값과 연결한다.

## 주요 흐름

1. 사용자가 영어 검색 결과에서 `/en`을 연다.
2. 5일장 설명과 ‘현재 시장 지도는 한국어 이름·주소를 사용한다’는 안내를 읽는다.
3. `Explore the market map`으로 `/en/map`에 간다.
4. 영어 시·도 검색, 필터·목록·상세 시트에서 한국 기준 일정을 확인한다.
5. `Maps & directions` 버튼 하나를 눌러 지도 서비스를 선택하거나 별도 공유 버튼으로 시장 링크를 공유한다. 좌표가 없으면 지도 선택을 표시하지 않는다.

지도 앱 선택 목록에는 `NAVER Maps — Directions`와 `Google Maps — View location`을 제공한다. NAVER는 현재 경로 연결을 유지하고, Google은 좌표로 시장 위치를 여는 링크를 쓴다. Google에서 한국 내 경로 안내가 가능한 것처럼 약속하지 않는다. 한국어 화면도 `지도·길찾기`라는 동일한 단일 버튼 구조를 사용한다. 선택 목록은 상세 시트 안에서 펼쳐지며 별도의 중첩 시트나 상시 노출되는 서비스별 버튼을 만들지 않는다. 지도 서비스가 늘어도 첫 화면의 동작은 하나다.

지도 배경에 NAVER가 그리는 지명, 외부 지도 화면, 시장 고유명사는 한국어로 남을 수 있다. 독립 시장 상세·About·온누리 가이드·제보 폼·법률 문서로 이어지는 링크에는 `(Korean)`을 붙인다. 영어 지도에서 독립 시장 상세로 이동할 경우 한국어 페이지라는 사실을 링크에서 알 수 있게 한다.

## 경로와 콘텐츠 정책

- 영어 안내는 `/en`, 영어 지도는 `/en/map`이다. 공유 가능한 선택 상태·날짜·검색어는 영어 지도 URL의 쿼리에 유지한다. 영어 목록 항목을 새 탭으로 열어도 영어 지도와 같은 상태가 유지된다.
- 공유 링크의 직접 선택일이 이미 지난 날짜라면 한국 기준 오늘로 조정한 사실을 영어로 알린다. 시장 ID가 없거나 필터와 맞지 않아 선택이 해제될 때도 결과 목록으로 돌아왔음을 알린다. 조용히 다른 시장·날짜를 보여주지 않는다.
- 언어 전환 시 지도에서 선택한 시장·날짜·필터·검색어를 가능한 한 보존한다. 검색어를 자동 번역하지 않는다.
- 영어 지도에서는 기존 시장의 한글 독립 상세 URL을 기본 공유 대상으로 삼지 않는다. 영어 지도 선택 상태의 `/en/map?...`을 공유한다.
- 영어 안내의 대표 주소(canonical)는 `/en`, 영어 지도의 대표 주소는 `/en/map`이다. 쿼리별 페이지를 별도 영어 문서로 홍보하지 않는다.
- 영어 안내 페이지를 sitemap에 추가한다. 영어 지도는 영어 본문이 빈약한 탐색 도구이므로 초기에는 sitemap에 넣지 않고 `noindex, follow`를 적용한다.
- 한국어 홈과 영어 안내는 내용이 다르므로 상호 번역본 hreflang으로 연결하지 않는다. 영어 지도와 한국어 지도도 초기에는 화면 구성·독립 상세 범위가 달라 hreflang을 유보한다.
- 영어 콘텐츠 영역은 `lang="en"`, 한국어 고유명사·예시는 `lang="ko"`로 표시한다. 현재 공통 루트 `<html lang="ko">`를 영어에 맞추려면 라우트 그룹 재배치가 필요하므로 첫 출시에서는 영역별 언어 지정을 사용한다. 문서 전체 언어까지 정확히 나누는 작업은 후속 국제화 단계에서 진행한다.
- 자동 언어 감지·강제 이동·번역 라이브러리는 사용하지 않는다.

## 영어 안내 페이지의 메시지

- H1: **Find Korean Traditional Market Days by Date**
- 소개: *Choose a travel date and region to find traditional market days across Korea.* 사용자가 실제로 할 수 있는 날짜·지역 탐색을 첫 문장에 둔다.
- 상설시장과 장날: 상설시장은 점포가 정기적으로 운영되는 시장이고, 장날은 날짜를 정해 장이 서는 날이다. 둘은 서로 배타적인 시장 종류가 아니다. 상설 점포가 있는 시장에도 정기 장날이 열릴 수 있다.
- 장날의 매력: 장날에는 평소보다 더 많은 판매자가 모여 판매 물품과 구경거리가 훨씬 풍성해지는 경우가 많다. 여행자는 단순히 ‘문 여는 날’을 찾는 것이 아니라, 장날 특유의 규모와 활기를 경험할 날짜를 찾는다. 시장마다 규모와 구성은 다르므로 모든 장날에 같은 수의 판매자나 행사·공연이 있다고 약속하지 않는다.
- 영문 본문 초안: *A permanent market has shops you can visit on regular days. Market days are often the liveliest time to visit: many more vendors may gather, bringing a wider range of goods and much more to see than on an ordinary day. Some markets have both permanent shops and scheduled market days. The number of stalls varies, and individual shops may have different hours.*
- 5일장: 2·7일장이라면 매월 2·7·12·17·22·27일이라는 구체적인 예시를 사용한다. 모든 시장이 같은 규칙이라고 말하지 않는다.
- 방문 안내: 기록된 장날이 모든 점포의 영업이나 운영 시간을 보장하지 않는다. 출처를 확인하도록 안내한다.
- 지도 연결: 시장 이름과 주소는 현재 한국어 원문을 사용한다고 미리 알린다.
- 날짜 기준: 영어 지도의 Today·Next 7 days·This weekend·다음 장날은 같은 순간 어디에서 접속하든 한국 표준시(Asia/Seoul)의 날짜를 기준으로 계산한다. 한국 자정이 지나거나 백그라운드 탭으로 돌아오면 Today를 갱신한다. 사용자가 직접 선택한 날짜는 달력 날짜 그대로 해석한다. 화면에 Korea time (KST)을 표시한다.
- 필터 의미: 기존 Today·Next 7 days·Weekend는 정기 장날을 중심으로 결과를 좁혀 상설시장 일부를 제외한다. 영어 문구는 `Market days today`처럼 실제 결과를 설명하고, `All markets`에서 상설시장을 볼 수 있다고 안내한다. 이번 리뷰는 필터 포함 로직을 변경하지 않는다.

## 완료 기준과 출시 후 확인

- `/en`에서 JavaScript 없이도 영문 설명·영어 지도 링크를 읽을 수 있다.
- `/en/map`에서 검색·날짜 선택·목록·시장 선택·상세 시트·공유·오류 복구를 한국어 UI 문구 없이 수행할 수 있다. 시장명·주소·지도 배경의 한글은 예외다.
- 영어 지도에서 시장을 공유하고 링크를 다시 열면 영어 화면과 선택 상태가 유지된다. 모바일 뒤로 가기도 같은 언어 경로에 머문다.
- 시장 상세에는 지도 서비스별 버튼 대신 `Maps & directions`/`지도·길찾기` 동작 하나가 보인다. 펼친 선택 목록에서 NAVER는 경로로, Google은 좌표 위치로 열린다. 선택 목록은 키보드로 조작하고 닫을 수 있다.
- 17개 시·도 영문 검색이 결과를 내고 한글 검색도 유지된다. 한국·미국·영국 시간대에서 같은 순간 Today와 다음 장날이 같은 한국 달력 날짜를 가리킨다.
- 영문 페이지의 메타데이터·대표 주소·색인 설정이 실제 콘텐츠와 일치한다.
- 320·375·430px에서 긴 영어 문구가 메뉴·필터·시트를 넘치게 하지 않는다.
- 기존 한국어 경로와 테스트가 유지된다.
- `/en`에서 상설시장과 장날의 차이, 한 시장에 둘 다 있을 수 있다는 점, 장날에는 물품·볼거리가 더 풍성해질 수 있다는 점, 점포별 영업은 보장하지 않는다는 점을 읽고 이해할 수 있다. 데이터에서 `상설장`이면서 `digit-pair` 일정인 사례도 모순으로 취급하지 않는다.
- 공개 후 Search Console에서 `/en`의 색인·영어 검색 노출·클릭을, Umami에서 `/en`·`/en/map`의 방문을 확인한다. Direct를 영어 검색 유입으로 간주하지 않는다. 새 이벤트가 없어 지도 클릭 전환율은 계산하지 않는다.

## 기획 당시 코드에서 확인한 영향 범위

기획 당시 `MarketExplorer`는 URL을 `/`로 고정해 갱신하고 시장 선택 때 한국어 상세 경로를 만들었다. `MarketFilters`, `MarketList`, `MarketMap`, `MobileMarketSheet`, `MarketDetail`, `MarketShareButton`, `OnnuriSummary`, `SiteFooter`, `MobileAppBar`에는 한국어 문구가 있었다. 날짜 표시와 일정 계산은 기기 현지 날짜를 사용했다. 구현에서는 화면 문구·영어 경로·시도 검색 별칭·한국 날짜 기준을 함께 정리했으며 시장 원본 데이터는 변경하지 않았다.

시장 원본에는 `marketType`이 `상설장`이면서 `schedule.kind`가 `digit-pair`인 항목이 153곳 있다. 따라서 영어 안내에서 permanent market과 market day를 상호 배타적 범주로 설명하면 데이터와 맞지 않는다.

기획 당시 작업 트리는 `origin/main`보다 커밋 하나 뒤에 있었다. 구현은 최신 main을 기반으로 한 `codex/english-traveler-map` 브랜치에서 진행해 `MobileHomeControls`와 `MarketPreview`를 영어화 대상에 포함했다.

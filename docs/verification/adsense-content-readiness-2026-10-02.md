# AdSense 콘텐츠 보완 검증 — 2026-10-02

대상: main `c421ec7`에서 시작한 `codex/adsense-content-readiness`의 로컬 변경. 배포·Search Console 검사·AdSense 재심사는 아직 수행하지 않았다.

## 변경과 근거

- 초기 HTML의 임시 1/15 날짜 및 로딩/실패 상태의 시장 0곳 표시를 제거했다. 실제 빈 결과는 계속 0곳으로 표시한다.
- 대표 시장 5곳의 설명과 링크를 초기 HTML에 포함하고, 나머지 25개 링크는 자바스크립트 없이 동작하는 details/summary로 제공한다.
- 홈의 안내 바로가기, 스크롤 영역의 서비스·출처·개인정보·제보 링크를 제공한다. 바로가기는 JS 환경에서 기존 popstate 처리와 충돌하지 않도록 직접 스크롤하고, JS가 없으면 기본 앵커 링크로 동작한다.
- 30개 시장 안내를 공식 관광·지자체·시장 자료로 재검토했다. 개별 사실과 미확인 범위는 [출처 조사 기록](adsense-editorial-audit-2026-10-02.md)에 정리했다. 직접 방문하거나 원본 공공데이터를 새로 내려받은 작업은 아니다.
- 서귀포향토오일시장의 기존 5·10일장을 비짓제주 근거에 따라 4·9일장으로 정정했다. 원본 ID와 주소는 유지하며 생성기에도 같은 정정을 반영했다. `scheduleSource`는 원본 데이터 기준일과 별도의 정정 근거다.
- 상설시장에 대한 무조건적인 오늘 운영 표시를 제거하고, 상세 답변 및 SEO에 점포별 휴무 확인 안내를 반영했다.
- 편집 확인일과 원본 데이터 기준일을 구분하고, 사이트맵 수정일은 두 날짜 중 더 최근 값을 사용한다.

## 기존 디자인 검사 실패 (이번 코드 변경으로 생긴 실패가 아님)

전체 E2E 최초 실행에서 다음 3개 검사 × 3개 뷰포트가 실패했다. 현재 배포 사이트 `https://kmarketday.com`을 대상으로 동일 검사를 다시 실행해 같은 기대값 불일치를 재현했다.

- `mobile-design-fidelity.spec.ts`: 버튼 높이 44px 기대, 실제 48px.
- `mobile-overflow.spec.ts`: 가로 스크롤 기대, 실제 overflow visible.
- `mobile-ux-regression-001.spec.ts`: 한 줄 가로 넘침 기대, 실제 줄바꿈.

main의 기존 CSS는 이미 버튼 48px·16px 글꼴·줄바꿈을 지정한다. 이번 작업에서 그 디자인이나 위 3개 테스트의 기대값은 변경하지 않았다. 전체 E2E가 모두 통과했다고 해석하면 안 된다. 최초 실행의 추가 9건은 새 안내/푸터 링크로 인한 테스트 선택자 중복이었으며, 메뉴·검색 목록 범위로 선택자를 한정한 뒤 통과했다.

## 검토와 재현

- 초기 HTML·로딩 상태, 네이티브 안내, 확인일·사이트맵, 일정 정정은 먼저 실패하는 회귀 테스트를 실행한 뒤 수정했다.
- 독립 코드 검토에서 상설시장 SEO의 영업 단정이 발견되어 수정하고 회귀 테스트로 확인했다. 그 외 중대한 코드 결함은 보고되지 않았다.
- 실제 브라우저 확인에서 안내 앵커와 기존 popstate 처리의 충돌을 발견했다. 뷰포트 이동 실패를 E2E로 재현한 뒤 수정했고 세 화면 크기에서 통과했다.
- 로컬 빌드에는 네이버 지도 클라이언트 ID를 주입하지 않아 지도 실패 대체 화면이 표시된다. 지도 공급자의 실제 운영 환경 연결은 배포 후 확인 대상이다.
